My agent's idea of saving tokens: burn 6.7 million of them, then write a 700-line eulogy for the encoder it deleted.

`main.ts` (Node 22) writes the roast to `/output/entry.txt` (116 characters, 116 bytes, one line, within the 1–200 gate). No network, no dependencies.
